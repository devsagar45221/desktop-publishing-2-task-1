# desktop-publishing-2-task-1
Practical 01: Introduction to Adobe Photoshop
Steps to Perform
Open Adobe Photoshop and create a new document using File → New.
Set the document width to 1200 pixels and height to 800 pixels. Select RGB Color mode and a white background.
Explore the Photoshop interface, including the Menu Bar, Toolbar, Options Bar, Layers Panel, and Properties Panel.
Select the Move Tool (V) and use it to move objects around the canvas.
Select the Marquee Tool (M) to create rectangular or elliptical selections.
Select the Lasso Tool (L) to make freehand selections.
Select the Brush Tool (B) to draw strokes and add decorative elements.
Select the Eraser Tool (E) to erase unwanted parts of the design.
Select the Crop Tool (C) to adjust the canvas composition if required.
Select the Shape Tools (U) to create at least three shapes, such as a circle, rectangle, and triangle. Apply at least two different colors.
Select the Type Tool (T) and add your Name, Roll Number, and Course to the composition.
Use the Move Tool to arrange the shapes and text neatly on the canvas.
Organize the Layers Panel by renaming layers and adjusting their order.
Save the editable Photoshop document using File → Save As in PSD format with the filename Practical_01_Name_RollNo.psd.
Export the final composition using File → Export → Export As. Select JPG format and save it as Practical_01_Name_RollNo.jpg.
Verify that both files are saved correctly and that the final image has dimensions of 1200 × 800 pixels.
